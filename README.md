# kickstart.nvim

## Introduction

A starting point for Neovim that is:

- Small
- Single-file
- Completely Documented

**NOT** a Neovim distribution, but instead a starting point for your configuration.

## Features

- Copilot Chat
- LSP
- Treesitter
- Telescope
- Git
- Completion
- Snippets
- Lualine
- Markdown Preview
